# Global Pulse & Tech Daily (द्विभाषी गूगल एफिलिएट एवं ब्लॉगिंग प्लेटफॉर्म)

An automated, high-converting Google AdSense & Affiliate Marketing blogging website featuring automated daily publication in **English and Hindi (हिन्दी)** across four key pillars:
- 📰 **News (ताज़ा समाचार)**
- 🏛️ **Politics (राजनीति एवं कूटनीति)**
- 💹 **Finance (एल्गोरिथमिक फॉरेक्स एवं बिटकॉइन विश्लेषण)** — *Focused on quantitative Forex (EUR/USD, GBP/USD) & Bitcoin (BTC) automation; strictly zero gold and zero manual trading.*
- 🔬 **Science & Technology (विज्ञान एवं प्रौद्योगिकी)**

---

## 🚀 Key Features

1. **Dual Language Engine (हिन्दी + English)**:
   - Full bilingual support with Devnagari typography (`Noto Sans Devanagari`) and modern English (`Inter`).
   - One-click instant language toggle inside articles (`[ 🇬🇧 Read in English ]` / `[ 🇮🇳 हिन्दी में पढ़ें ]`) without page reload.
   - Global language switcher with cookie persistence and `hreflang="en"` / `hreflang="hi"` SEO tags.

2. **Google AdSense & Affiliate Monetization Ready**:
   - Header 728x90 Leaderboard responsive ad slot.
   - In-article responsive banner units.
   - Sidebar 300x250 Medium Rectangle unit.
   - Targeted in-article Affiliate Product Callout Box with high CTR buttons.
   - Built-in AdSense Publisher ID (`ca-pub-XXXXXXXXXX`) configuration in the Admin dashboard.
   - Full FTC and Google Publisher compliance pages: **Privacy Policy**, **Terms of Service**, **Affiliate Disclosure**, **About Us**, and **Contact Us**.

3. **Daily Automated Posting & On-Demand Test Generator**:
   - Background scheduler (`schedule`) that automatically generates and publishes daily bilingual articles every morning.
   - **⚡ 1-Click Instant Test Generator**: Generate a new bilingual post anytime directly from the Admin console or sidebar widget across any chosen category.

4. **SEO & Discovery**:
   - Dynamic `/sitemap.xml` with bilingual URL alternate tags.
   - Dynamic `/feed.xml` RSS 2.0 feed for Google News and syndication.
   - Valid `/robots.txt`.
